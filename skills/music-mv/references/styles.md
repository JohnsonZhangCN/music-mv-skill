# 风格映射

## 小镇姑娘：参考的是视觉语法

先查看 ../assets/painted-animation/docs/xiaozhen-sheet.jpg，必要时阅读 ../assets/painted-animation/examples/xiaozhen/STORYBOARD.md 与两份场景代码。

- 材质：暖白纸底，水彩晕染，墨线边缘，少量排线与纸颗粒。
- 角色：厚实的简化轮廓、保持参考图的配色和标志物；关键表演使用预备、挤压拉伸、停顿和跟随。12 次绘制/秒的线条轻微变化；成片默认 24fps。
- 色彩：一幕使用少量颜色。示例采用黄昏、棕褐回忆、靛蓝夜晚的变化。可根据歌曲情绪换成暖橙、粉色、天空蓝和奶油色，保持纸墨质感。
- 场景：有可重复识别的生活空间和道具。示例的车站、火车、花朵属于原歌叙事，新歌要重新选择意象。
- 叙事：用动作演歌词，例如想念化为信号、喷嚏引出爱心、手机铃声引出关心；字幕只承担歌词，不代替表演。
- 转场：动作接续、烟雾遮罩、道具变形、笔刷擦拭、窗框/门框遮挡；落在音乐节拍附近，同时保留清楚读懂动作的时间。
- 结尾：呼应开场的动作或道具；用户指定精确范围时在该边界收住，不延长音乐。

针对《爱你》的建议：保持手绘世界，采用更明快的甜蜜小镇配色；橙色角色与粉色花朵角色互动。这是创作建议，不是原示例必须照搬的镜头。

## 其他可映射风格

| 用户描述 | 在本引擎中的处理 |
|---|---|
| 水彩绘本、温暖治愈 | 水彩块面、留白、柔和色彩、舒缓镜头 |
| 墨线漫画、俏皮 | 强轮廓、快速预备动作、表情特写、少量漫画效果 |
| 复古手绘、怀旧 | 有限色盘、棕褐调、纸颗粒、有限动画 |
| 写实真人、3D 电影 | 说明需要另一套生成/渲染后端；不要声称本模板可以原样实现 |
