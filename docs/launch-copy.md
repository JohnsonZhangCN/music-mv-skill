# 《爱你》发布文案

## 视频说明

给这两个小家伙安排了一支《爱你》MV。

角色图、歌曲、歌词交给 Claude Code，Opus 写代码画出了这条小巷，也画出了两个人隔着窗户的小心思。

做完顺手把流程整理成了 /music-mv：给角色图、歌曲、LRC、截取时间和画风，就能继续做自己的手绘 MV。补了音频裁剪、歌词同步和 Windows 本地渲染，放在 GitHub 了：

https://github.com/JohnsonZhangCN/music-mv-skill

手绘引擎基于 painted-animation，原项目和作者都在仓库里注明了。喜欢这类画风的可以拿去试试。
